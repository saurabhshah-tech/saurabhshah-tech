## What you'll find here

I'll use this space to document and recreate some of the engineering problems I've worked on using standalone examples and synthetic data.

That will include a mix of:

- architecture and design notes
- small reference implementations
- infrastructure examples
- engineering patterns
- experiments and POCs
- performance and failure testing
- things I've learnt while debugging production systems

Some of the areas I'm planning to cover:

### AI platform

LLM gateway architecture, Bedrock, model routing, access controls, budgets, token usage, caching, evals and observability.

### Platform engineering

EKS, workload isolation, infrastructure automation, CI/CD, internal developer platforms and other platform-related work.

### Engineering metrics

A small serverless implementation for collecting engineering data, processing it and querying it using services such as Step Functions, S3 and Athena.

### Observability

OpenTelemetry, Grafana Alloy, metrics, logs, traces and practical monitoring patterns across AWS and Kubernetes.

### Reliability

Load testing, dependency failures, fail-open vs fail-closed behaviour, scaling and understanding what actually happens when part of a system goes down.

## A bit about how I work

I like getting into the details of how systems behave rather than stopping once the architecture diagram looks good.

A lot of the interesting work usually starts with questions like:

- What happens when this dependency is unavailable?
- How do we know this is working in production?
- What happens when we scale it?
- Where is the bottleneck?
- What does this cost?
- Can we make this simpler for the teams using it?

That's the sort of work I plan to capture here.
